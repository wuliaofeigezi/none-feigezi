# 霓虹竞技场 Neon Arena — War Robots 风格 3D 联机机甲对战

基于 **Three.js + Socket.IO + Node.js** 的 3D 联机机甲对战游戏。服务器权威同步（20Hz），机甲模块化血量系统全局生效。

## 机甲（模块化血量）
- **人形战斗机器人**：双腿(各100) + 胸部(250) + 藏于胸部的核心；肩部 4 战斗模块槽；损毁 1/2 条腿移速 -50%/-80%（瘸腿动画）
- **蜘蛛机器人**：六腿(各50) + 胸部(100) + 核心；胸部两侧+顶部 3 模块槽；腿损毁减速 5%/25%/50%/80%/95% 递增、6 腿瘫痪
- 胸部血量耗尽后，命中胸部的攻击有概率穿透伤害核心；**核心被击即死**
- **机甲在局内选择**：开局与死亡后弹出机甲选择面板（选择期间不可移动/攻击），死斗只能选未损毁的机甲

## 战斗模块（武器）
- **Gau12“破坏者”30mm 机炮**：720 发/分，备弹 480，装填 15s，不可边打边装填，每发 2 伤害（稳定持续输出）
- **镭射激光**：光束接触期间每秒 32 伤害，满充能 20s，持续照射上限 12s，可边打边充（能量伤害可绕过量子罩；均衡调整后平均 DPS 与机炮接近）
- **巡飞弹**：弹夹 5 发一次性打出，装填 15s，有散布，弧线越地形打击，每发命中模块 12 伤害（爆炸半径 2.4m，爆发 AOE）

## 模式
- **死斗（Duel，主模式）**：红蓝两队，**每小局（回合）一条命，死亡即出局观战，下一回合全员复活**；靠近敌方基地核心部署装置 10 秒可摧毁核心直接获胜，或全灭对方；先赢 13 回合获胜
- **战旗（CTF）**：夺旗卡牌赛（抽卡投票 + 夺旗得分）
- **占点（Zone）**：占领区定时迁移，站桩得分先到 120 分获胜
- **死亡竞赛（FFA）**：经典击杀得分（死亡 10 秒后复活；死斗不可复活改观战）
- **人机**：房主开局前可选加入 0-5 台人机（Bot 自动索敌攻击）；对局中真人加入时自动替代人机席位

## 操作
WASD/摇杆移动 · 鼠标/滑动瞄准 · 左键/开火键射击 · 空格跳跃 · **ESC 打开暂停菜单（可自杀）** · **长按 J 3 秒自杀** · **M 大地图**（按住）
- **第三人称视角**：相机跟随机甲后方（防穿墙），自机机甲模型可见
- **武器索敌锁定**：准星对准敌人自动锁定（显示锁定框与距离），锁定后即使移开准星，武器也精准命中锁定目标；瞄向其他敌人自动重锁；锁定显示目标距离

## 机甲与地图
- 蜘蛛机器人六条腿 60° 均匀环绕胸部，**可爬墙**（贴墙朝墙移动即攀爬，越过墙顶自动脱离）；腿部损毁减速 5%/25%/50%/80%/95% 递增、6 腿瘫痪
- **守护者（新）**：重型塔盾机甲，头顶槽**固定为量子防护罩模块**（不可更换，只能自由配置两个肩部武器槽）；**F 键点击切换**升起/收回：升起阻挡所有物理伤害、期间无法移动；耐久上限 300，受击 2s 后随时间缓慢恢复，耗尽自动破盾；激光为能量伤害可绕过护罩
- 地图精细化：14m 高围墙、四角高塔、纵向/横向分隔高墙（留缺口）、二层平台、低矮掩体；跳跳台可跃过高墙

## 机库（原大厅）
机库中可查看三台机甲（泰坦/猎蛛/守护者）并点击战斗模块槽循环切换武器（机炮/镭射/巡飞弹），顶部**战斗**按钮按所选模式开房，模式可选死斗（默认）/战旗/占点；**机甲在开局与死亡后于局内选择**。

## 房间流程
创建房间获得 6 位房间码 → 分享给好友加入（可设密码）→ 房主选择模式/人数/时长 → 开局；对局中可中途加入，断线后同 sessionId 重连恢复角色（房间席位自动迁移）。

## 本地运行
```bash
npm install
npm run vendor     # 拷贝 three.js / socket.io 客户端库到 public/js
npm start          # http://localhost:3000
```

## 测试
```bash
npm test           # 确定性逻辑测试（物理/机甲模块/武器/死斗/占点/席位迁移），无需启动服务器
npm run test:smoke # 冒烟测试（完整房间流程 + 自杀 + 断线重连 + 席位迁移），需先 npm start
```

## 部署
```bash
# 1. 安装依赖并 vendor
npm install && npm run vendor

# 2. 创建凭据文件 deploy/creds.json
#    {"host":"服务器IP","user":"root","password":"密码"}

# 3. 一键部署（上传 → 装 Node → systemd 常驻 → nginx 反代 + WebSocket）
npm run deploy
```

## 目录结构
```
server/      游戏服务器（权威逻辑、地图、20Hz 状态同步、房间大厅）
  index.js   入口（Express 静态托管 + Socket.IO）
  rooms.js   房间大厅（RoomManager / Room，席位迁移、断线重连分发）
  game.js    核心对局逻辑（FFA / 占点 / CTF 卡牌，20Hz 权威 tick）
  map.js     地图数据（障碍物、跳跳台、出生点、血包）
public/      客户端（Three.js 渲染、输入、插值、HUD）
  js/main.js         客户端主逻辑（本地预测物理、渲染插值、触屏/键鼠）
  js/neon-shared.js  客户端/服务端共享常量与工具（唯一事实来源，两边都从这里取）
deploy/      部署脚本（vendor 拷贝、SSH 上传与配置）
test/        逻辑测试（npm test）与冒烟测试（npm run test:smoke）
```
